# 🐍 Snake Game

A classic Snake Game built using **HTML5 Canvas**, **CSS**, and **Vanilla JavaScript**. Control the snake, eat food to grow longer, and avoid colliding with yourself. This project demonstrates fundamental JavaScript concepts such as arrays, DOM manipulation, keyboard events, game loops, collision detection, and the HTML5 Canvas API.

## ⚙️ How It Works

1. The snake starts with one segment.
2. The player controls the snake using the arrow keys.
3. Food appears randomly on the canvas.
4. When the snake eats the food:
   - The snake grows longer.
   - A new piece of food appears at a random location.
5. The game continues until the snake collides with itself.
6. The player can refresh the page to start a new game.
